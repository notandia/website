Privacy policy for Notandia

Last updated: July 29, 2026

The Firefox version of Notandia has not yet been signed or published. Current source adds configurable publisher watchlists and optional formal post-publication checks. Most processing occurs locally in Firefox.

Notandia is independent and is not affiliated with, authorized by, or endorsed by MDPI AG, Frontiers Media SA, Crossref, Retraction Watch, NCBI, Mozilla, or any publisher or data provider.

Publisher profiles and local processing

Content scripts inspect page structure, links, citation text, scholarly identifiers, and publisher evidence. Built-in MDPI and Frontiers settings and custom publisher names, domains, DOI prefixes, actions, colors, and confidence policies are stored through Firefox extension storage and processed locally.

These profiles are not sent to the developer, Crossref, NCBI, publishers, or an analytics provider. Custom profiles are validated declarative data and cannot contain scripts or executable selectors.

NCBI metadata lookups

When enabled, the extension sends only validated DOI, PMID, or PMCID values to the NCBI ID Converter over HTTPS. Requests identify the application as notandia, omit browser credentials and referrers, and are deduplicated, batched, and rate-bounded.

Optional Crossref integrity lookups

This feature is off by default. Enabling it is a user action, and Firefox presents an additional optional websiteContent data permission describing transmission of website-derived DOI identifiers. Denial means no Crossref integrity requests are made.

After consent, normalized DOI identifiers are sent to Crossref to retrieve formal update relationships. The extension may query both a DOI’s direct record and a reverse updates:<doi> relationship for separately registered notices.

Requests omit the page address, article text, citation text, publisher-profile settings, search query, browsing history, cookies, account identifiers, analytics identifiers, and referrers. A scan attempts no more than 50 DOI records and starts no more than four requests per second. Disabling the feature cancels active and queued requests and removes the optional permission where supported.

Pre-release identity

The first Firefox submission is planned to use Gecko ID browser-extension@notandia.github.io. Because Firefox has not been released, this is a pre-release identifier rather than an existing-user compatibility identity.

Issue reports

Report article/context issue opens an editable public GitHub draft. It may prefill the selected category, page origin and path without query or fragment, extension and browser version, enabled publisher-profile IDs, and integrity-check state. It does not automatically include citation text or DOI lists.

Retention and control

  • Preferences remain in Firefox extension storage until changed, cleared, or the extension is removed.
  • Per-tab publisher, reference, and integrity data is cleared when navigation begins or a tab closes.
  • Crossref responses may remain in extension memory for up to 24 hours and are not used to build browsing history.
  • Users can independently disable MDPI, Frontiers, custom profiles, NCBI requests, integrity requests, and optional permissions.

Interpretation and commercial use

A publisher watchlist match is a user-selected display rule, not an objective quality score. No known integrity signal is not a guarantee of reliability.

The extension contains no advertising, product analytics, or remote executable code. The developer does not sell, rent, or share page content, browsing history, publication identifiers, or preferences for advertising, profiling, or data-broker purposes.

Security and contact

The extension uses Manifest V3-compatible components, validated configuration and cross-context messages, bounded inputs and caches, a self-only content security policy, and no shipped runtime npm dependencies. Sensitive vulnerabilities should be reported privately through GitHub Security Advisories.
