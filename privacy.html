Privacy

Research context should not become browsing surveillance.

This overview describes Notandia’s common privacy boundary. Each browser has a platform-specific policy whose terminology, storage behavior, and permission flow match that platform.

Notandia, previously distributed as MDPI Filter, is independent and open source. It is not affiliated with, authorized by, or endorsed by MDPI AG, Frontiers Media SA, Crossref, Retraction Watch, NCBI, browser vendors, or any publisher or data provider.

Local publisher profiles

The extension processes page structure, links, citation text, scholarly identifiers, and publisher evidence locally. Built-in MDPI and Frontiers preferences and custom publisher names, domains, DOI prefixes, actions, colors, and confidence policies remain in browser extension storage. They are not sent to Notandia, Crossref, NCBI, publishers, or an analytics provider.

Custom profiles are validated declarative data. They cannot contain executable scripts, remote code, or arbitrary page selectors.

NCBI metadata lookups

When enabled, NCBI lookups transmit only validated DOI, PMID, or PMCID values needed to resolve publication metadata. Requests identify the application as notandia, omit browser credentials and referrer information, and are deduplicated, batched, and rate-bounded. Disabling NCBI lookups causes zero related requests but may reduce publisher-detection coverage when a page exposes only indirect identifiers.

Optional Crossref integrity lookups

This feature is off by default. After explicit user consent, the extension may transmit normalized DOI identifiers to Crossref solely to retrieve scholarly metadata and formal post-publication relationships. It may check both the DOI’s direct record and a reverse updates:<doi> query for separately registered notices.

It does not send the page address, article text, citation text, publisher-profile settings, search query, browsing history, account identifier, or analytics identifier. Each scan attempts no more than 50 unique DOI records and starts no more than four requests per second. Disabling the feature stops new requests and cancels active or queued work. Firefox requires an additional optional website-content permission.

Issue reports

Choosing Report article/context issue opens an editable public GitHub draft. It may prefill the selected category, sanitized page origin and path, extension and browser version, IDs of enabled publisher profiles, and whether integrity checks are enabled. Query parameters, fragments, citation text, and DOI lists are omitted unless the user adds them.

Interpretation limits

A publisher-profile match is a user-selected display rule, not an objective quality score. “No known integrity signal” means only that none was found in checked records; it is not a guarantee that a work or publisher is reliable.

Retention and user control

  • Publisher profiles and preferences remain in extension storage until changed, cleared, or the extension is removed.
  • Per-tab publisher, reference, and integrity data is cleared when navigation begins or a tab closes.
  • Crossref responses may be cached only in extension memory for up to 24 hours and are not used to create persistent browsing history.
  • Users can disable any publisher profile, disable network-assisted features, deny optional permissions, clear extension data, disable the extension, or uninstall it.

No analytics or commercial sharing

The extension and website contain no advertising or product analytics service. The developer does not sell, rent, or share page content, browsing history, publication identifiers, or preferences for advertising, profiling, or data-broker purposes.

Website

The project website contains no analytics, advertising, account system, database, cookies, or remote JavaScript. Cloudflare may process ordinary network and security metadata needed to deliver the site under its infrastructure terms.

Reporting a privacy issue

Use the relevant repository’s private security process for sensitive reports. Do not post private browsing data, access tokens, unpublished manuscripts, or personal information in a public issue.
